# Guardlings

Мобильная игра в жанре tower defense: монстры-стражи защищают портал от диких монстров.
HTML5 + Phaser 3, вертикальный экран, управление касанием.

- Запуск: открыть `index.html` в браузере (интернет не нужен).
- Журнал разработки, решения и планы: `DEVLOG.md`.
- Баланс и настройки: `src/config.js`. Тексты на двух языках: `src/i18n.js`.
- Публикация: GitHub Pages из корня основной ветки (файл `index.html` лежит в корне).
